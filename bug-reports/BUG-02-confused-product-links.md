## BUG-02: У пользователя problem_user перепутаны ссылки ведущие на карточки товаров

**Тип:** Bug
**Срочно:** Да
**Метки:** Frontend (Каталог)
**Окружение:** Windows 11 26H2, Яндекс Браузер 26.8.5.811 (64-bit), 2560×1440

### Описание
У пользователя problem_user в каталоге перепутаны ссылки на товары. При нажатии на "Sauce Labs Backpack" происходит переход к карточке "Sauce Labs Fleece Jacket" и так у всех товаров

### Шаги воспроизведения
1. Открыть сайт https://www.saucedemo.com/
2. Войти под problem_user/secret_sauce (логин/пароль)
3. Нажать на карточку товара "Sauce Labs Backpack"

### Ожидаемый результат
При переходе на карточки "Sauce Labs Backpack" открываются корректная страница этого товара.

### Фактический результат
Открывается карточка "Sauce Labs Fleece Jacket". Аналогичное поведение наблюдается и для других товаров

### Severity
**Major**
Перепутанный переход по ссылкам может запутать и отпугнуть пользователя - что повлечет потери для бизнеса

### Priority
**Medium**
Баг воспроизводится только у тестового пользователя problem_user. В продакшене приоритет был бы High.
