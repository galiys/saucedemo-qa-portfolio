# Чек-лист: Авторизация
## Позитивные проверки
- [x] happy path (проверка входа с валидными данными standard_user) - переход к каталогу
- [x] Вход по кнопке Login (она активна и кликабельна)
- [x] Вход через нажатие Enter

## Негативные проверки
- [x] Вход с неверным логином/паролем (ошибка: Username and password do not match any user in this service)
- [x] Вход под заблокированным пользователем (ошибка: Sorry, this user has been locked out.)
- [x] Отправка пустых форм логин/пароль (ошибка: Username is required)
- [x] Отправка пустой формы пароль (ошибка: Password is required)

## Безопасность
- [x] Прямой заход на /inventory.html без авторизации - возврат на страницу логина
- [x] При выходе из аккаунта кнопка "Назад" в браузере не возвращаяет в систему (ошибка: You can only access '/inventory.html' when you are logged in.)
