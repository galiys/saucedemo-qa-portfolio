# QA Portfolio — SauceDemo

Учебный пет-проект по ручному тестированию веб-приложения [SauceDemo](https://www.saucedemo.com/).

## 🎯 Цель проекта
Продемонстрировать навыки тестирования веб-приложений: планирование, составление тестовой документации, поиск и оформление багов, анализ поведения системы.

## 🧪 Что тестировалось
- **Авторизация** — позитивные и негативные сценарии, разные типы пользователей
- **Каталог товаров** — отображение, сортировка
- **Корзина** — добавление, удаление, счётчик товаров

## 🛠️ Инструменты
- **Chrome DevTools** — анализ запросов, проверка вёрстки
- **Postman** — анализ HTTP-запросов приложения
- **Kaiten** — оформление баг-репортов
- **SQL** — примеры проверок данных (гипотетические)
- **GitHub** — хранение документации
