## TC-AUTH-01: Успешный вход с валидными данными

### Предусловия:
Пользователь не авторизован

### Шаги:
1. Открыть сайт https://www.saucedemo.com/
2. В поле логин ввести: standard_user
3. В поле пароль ввести: secret_sauce
4. Нажать на кнопку "Login"

### Тестовые данные
Стандартный пользователь:
**Логин:** standard_user
**Пароль:** secret_sauce

### Ожидаемый результат:
Произойдет переход на главную страницу каталога: /inventory.html

## TC-AUTH-02: Проверка входа с неверным паролем

### Предусловия:
Пользователь не авторизован

### Шаги:
1. Открыть сайт https://www.saucedemo.com/
2. В поле логин ввести: standard_user
3. В поле пароль ввести: 123
4. Нажать на кнопку "Login"

### Тестовые данные
Стандартный пользователь:
**Логин:** standard_user
**Пароль:** 123

### Ожидаемый результат:
Под полями ввода логин/пароль покажется ошибка: "Epic sadface: Username and password do not match any user in this service", пользователь остается на странице авторизации
