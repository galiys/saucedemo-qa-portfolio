# Тест-план SauceDemo

## Что тестирую
Сайт saucedemo.com для практики. Тестирем три модуля:
1. Авторизация
2. Каталог товаров 
3. Корзина

## Что не тестирую
- Мобилку — сайт десктопный
- Нагрузку и безопасность — не мой уровень пока
- API — у SauceDemo его нет публично, только смотреть запросы в DevTools

## Как тестирую
Вручную, в Яндекс Браузере Версия
26.8.5.811 (64-bit)/ Windows 11 26H2 
Основные виды:
- функциональное
- негативные сценарии (неверный пароль, пустые поля)
- UI — вёрстка, отображение
- problem_user, там заложены баги

## Тестовые данные
4 аккаунта с сайта: standard_user, locked_out_user, problem_user,
performance_glitch_user
Пароль у всех — secret_sauce

## Когда заканчиваю
Когда пройду чек-листы по всем трём модулям, оформлю баги
и напишу итоги в README.
